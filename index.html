How We Measure Reputation

Our scoring methodology is built on reproducible NLP pipelines and weighted sentiment models.

01
Data Ingestion
Continuous crawling of public data from social media platforms, e-commerce review APIs, horticulture forums, and trade publications. Only publicly available data is used.
02
NLP Processing
Transformer-based sentiment classification (fine-tuned on floriculture domain corpus) assigns positive/neutral/negative labels with confidence scores to each mention.
03
Weighted Scoring
Reputation Index = Σ(Sentiment Score × Source Weight × Recency Decay). Source weights: Social (1.0×), E-commerce (1.3×), Forums (1.1×), Trade Media (1.5×).
04
Real-Time Updates
Scores are recalculated every 6 hours. Confidence levels reflect data volume — varieties with fewer than 100 mentions display a low-confidence warning.
